# PDF Livre 1.1.0 — HTML único para uso offline

Baixe **pdf-livre.html**, salve no computador e abra no navegador atualizado. A conversão não exige Node.js, servidor local ou internet após o download.

- Interface, PDF.js, worker, JSZip e recursos auxiliares incluídos no HTML.
- Mesmo código-fonte organizado e disponível para contribuições.
- Bloqueio de conexões da aplicação por política de conteúdo.
- Markdown único ou ZIP em partes, com relatório de conferência.
- Licenças de código aberto incorporadas ao arquivo.
- SHA-256 disponível em `SHA256SUMS.txt`.

O mantenedor relata conversão anterior de um PDF gerado com 50.000 páginas e mais de 600 MB. Esse relato não constitui benchmark desta versão nem garantia para qualquer arquivo ou dispositivo. Não há OCR integrado; revise a extração.
